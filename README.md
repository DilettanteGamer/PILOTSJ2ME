# Pilots Resource Editor · 0.1.0

Самостоятельный редактор ресурсов Windows-версии игры. Исходники редактора
написаны отдельно; эта ветка имеет отдельную историю и не включает игровые
EXE/DLL, изображения, звук, реплики, оригинальные сценарии или декомпиляцию.
Для работы указывается локальная копия игры. Обработчики формата читают
данные из неё; игровой движок не встраивается и не эмулируется.

## Запуск в Windows 10/11 x64

В разделе **Actions → Windows editor** доступна сборка `PilotsEditor-Windows-x64`
после успешного выполнения workflow. Распакуйте весь архив и запустите
`PilotsEditor.exe`, сохраняя рядом папку `_internal` и лицензии зависимостей.

Из исходников, при установленном Python 3.11+:

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install .
.venv\Scripts\pilots-editor.exe
```

Редактор использует Qt/PySide6 и Pillow. Загрузка ресурсов крупного EXE
может занять время. Исходная папка и проекты не включаются в сборку редактора.

## Работа

1. **Открыть игру** — выбрать пользовательский `PILOTS.EXE`.
2. Выбрать секцию и ресурс. Дерево содержит фоны, предметы/персонажей,
   расстановку, анимации, изображения кадров, звук, музыку, условия,
   действия, карты и прочие блоки. Номера берутся из открытого файла.
3. На вкладке сцены видны фон, исходная расстановка и распознанные первые
   кадры инициализации. Это статический обзор: ветвления, анимационные
   состояния и загадки не исполняются. Нераспознанные объекты имеют маркер ID.
4. Объекты можно перетаскивать по ячейкам исходной карты. Служебные ячейки
   включаются отдельно. Колесо меняет масштаб, кнопка «Вписать» восстанавливает обзор.
5. Для изображения — PNG-экспорт/импорт; для реплики — WAV и прослушивание
   системным проигрывателем. Анимация просматривается покадрово и с таймером.
   Смещения кадров редактируются отдельно, свойства предметов — в инспекторе.
6. Текстовые префиксы сценариев редактируются в выделенном поле. В 0.1.0
   сохраняется выделенный размер строки, чтобы не сдвигать код/ссылки;
   длинная замена отклоняется с указанием лимита. Графические надписи
   заменяются как изображения. Строки внутри машинного кода EXE не редактируются.
7. Загадки представлены условиями, действиями, метаданными событий и
   картами исходной игры. Сейчас доступны HEX/бинарная замена, добавление,
   удаление и обмен наборами записей ID. Двойной щелчок на вкладке связей
   переходит к записи. Это редактор нативных данных, **визуальный конструктор
   новой логики и компилятор правил ещё не реализованы**.
8. **Сохранить проект** создаёт `.pweproj` с SHA-256 источника и заменами,
   без копии движка/всей игры. Изменённые ресурсы в пользовательском проекте
   могут содержать данные исходной игры; лицензия редактора на них не распространяется.
9. **Экспорт копии EXE** перестраивает индекс ресурсов, оставляя исполняемый
   префикс исходным. Исходный EXE не перезаписывается. Для проверки создайте
   отдельную копию папки игры и экспортируйте в её `PILOTS.EXE`.
   Остальные файлы игры должны оставаться рядом. «Запустить копию» использует
   исходный Windows-движок из экспортированной копии, а не код редактора.

Цвета PNG приводятся к палитре соответствующей сцены. Поддерживаются
непрозрачные/прозрачные пиксели, полупрозрачность отклоняется. Для реплик
нужен PCM WAV, mono, 8 бит, 11025 Гц. Музыка пока доступна как исходный
бинарный ресурс, без преобразования стандартного MIDI. Наборы ID сохраняют
исходные ID и ссылки; автоматическое переназначение зависимостей не выполняется.

## Форматы и границы

Редактор поддерживает индексированный ресурсный оверлей с окончанием `=VS=`.
В проверенной копии прочитаны 40 805 записей. Две нераспознанные секции
остаются непрозрачными и сохраняются побайтно. Поддержка других ревизий
определяется форматом, а не жёстко записанными игровыми правилами.

Проекты привязаны к SHA-256 источника.

## Разработка

```sh
python -m pip install -e .
QT_QPA_PLATFORM=offscreen python -m unittest discover -s tests -v
```

На Linux/macOS интерфейс можно использовать для просмотра и редактирования;
запуск оригинального EXE предусмотрен в Windows. Для локальной Windows-сборки:

```powershell
.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.venv\Scripts\python.exe scripts\build_windows.py
```

Пакет собирается в `dist/PilotsEditor`, без игры. Инструкции проверки и
дальнейшие этапы: [docs/DEVELOPMENT.md](docs/DEVELOPMENT.md).

MIT относится к новому коду редактора. Сведения о сторонних библиотеках:
[THIRD_PARTY.md](THIRD_PARTY.md).
