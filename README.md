# PILOTSJ2ME

Исходный код самостоятельно разработанного J2ME-порта и инструментов работы с ресурсами.

Оригинальные исполняемые файлы игры, библиотеки, декомпиляция, извлечённые изображения,
шрифты, звук, музыка, субтитры и готовые сборки с ресурсами удалены из публикуемой
истории веток. Для локальной сборки и работы инструментов нужна собственная копия игры.
Удалённые ресурсы и сборки не распространяются этим репозиторием.

- [Код порта и инструкции](j2me/README.md)
- [Документация разработки](docs/)
- [Независимый редактор ресурсов Windows](https://github.com/DilettanteGamer/PILOTSJ2ME/tree/windows-resource-editor)

История опубликованных веток очищена: старые идентификаторы коммитов и ссылки на сборки
больше не используются. Старые локальные ветки нельзя повторно отправлять на GitHub;
для публичной разработки используйте свежую копию очищенного репозитория.

Исторические технические отчёты могут содержать ссылки на удалённые артефакты.
Лицензии сторонних библиотек сохранены; права на оригинальную игру остаются у правообладателей.
