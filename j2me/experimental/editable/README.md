# Спрайты для ручной правки

[Весь корпус PNG — 34,3 МБ](Pilots-Sprites-128x160.zip) ·
[Только канализация — 0,95 МБ](Pilots-Sewer-Sprites-128x160.zip).

Архивы предназначены для компьютера. Полностью распакуйте ZIP в отдельную
папку и откройте `index.html` в браузере. Установка на телефон не нужна.

В каждом архиве:

- `images/` — индексные PNG пиксельных буферов версии 128×160, доступные для правки;
- `originals/` — исходные кадры для сравнения;
- `manifest.json` — номера кадров, длительность одного кадра в миллисекундах,
  исходные смещения/размеры, ID изображений и палитры;
- `index.html` — список анимаций с картинками и номерами кадров;
- `README.txt` — краткая инструкция.

Полный архив содержит 8625 уникальных изображений для 1667 ANM-анимаций,
архив канализации — 341 изображение для 37 анимаций. Дополнительные
изображения интерфейса/шрифтов и отдельные `.sprite` головоломок сюда
не включены. Графический корпус 0.27.22–0.27.24 одинаковый; исправления
канализации 0.27.24 меняют только загрузку и кэширование.

Для правки используйте `images/`: сохраните имя PNG, размер холста,
индексную палитру и прозрачный индекс 0. Работайте карандашом без
сглаживания. Один ID может встречаться в нескольких анимациях/локациях:
это указано в `shared_with_scenes` и ссылках кадров. Изображения PNG
показывают первую используемую палитру этого ID, другие палитры перечислены
в описании клипов. Пиксельные индексы общие.

Для переноса правок в сборку достаточно передать изменённые PNG с
прежними именами. Указатель позволяет найти все кадры, где они используются.
Маршруты, тайминги и исходные маски взаимодействия при такой визуальной
правке сохраняются. Импорт отредактированных файлов в текущий JAR
автоматически не выполняется.

Воспроизведение:

```sh
python3 j2me/experimental/export_sprites.py --include-originals
python3 j2me/experimental/export_sprites.py --scene 07 --include-originals --output j2me/experimental/editable/Pilots-Sewer-Sprites-128x160.zip
```

Экспорт проверяет, что каждый созданный PNG восстанавливает исходные
индексные пиксели без изменений. Он не меняет JAR или источники игры.
