В 0.27.17 I+ включает также небольшие банки заранее уменьшенных кадров трёх анимаций «Звериного двора». Больше I+ само по себе не означает больший объём чтения; C% включает их попадания в общий кэш сырых кадров. Размеры кэшей в байтах прежние, записей сырых кадров теперь 64.

С 0.27.16 AnimalScene читает пиксели по требованию при отрисовке и contains. Поэтому часть времени загрузок переходит из U в P; снижение одного U не доказывает ускорения. Сравнивайте FPS, P и отзывчивость курсора. L/B/I отражают чтения независимо от потока. Видимость V — флаг актора, а не результат отсечения за экраном.

С 0.27.14 для теста катсцены «Звериный двор» по умолчанию включена обычная подробная панель производительности (7 строк). Левой клавишей: подробная → краткая → выключено → аудиодиагностика → подробная. Размер буфера прежний. Внутренний номер третьей локации — S4. Для сравнения нужны несколько секунд катсцены без движения курсора и с движением; прежде всего U/P/L, B/I, C/R и M/N. F около 1 при A0 в покое не является доказательством просадки.

В 0.27.11 аудиопанель дополнена ошибками первоначального запуска: строка L/A/E/F — длительность чтения, этап последней ошибки, тип исключения и число отказов первичного запуска шагов. Строка K/C/P/H/X показывает cue, создания плеера, успешные первоначальные старты, повторные старты и отказы повторных стартов. При ошибке строка графических банков заменяется началом её текста. Этапы/типы перечислены в разделе 0.27.11 [README](../README.md). На обычной подробной панели (левая один раз) все прежние метрики остаются. Последняя ошибка не сбрасывается при успешном старте. Счётчики C/P/H/F до 999, X до 99, накопительно с запуска.

В 0.27.10 в аудиопанели добавлен `B`: число успешных повторных prefetch из состояния REALIZED (200), накопительно с запуска, на экране до 99. Z3 теперь означает завершённый плеер вне REALIZED/PREFETCHED. B в этой строке относится к MMAPI; B+ в строке графики по-прежнему означает чтения тайловых банков.

С 0.27.9 по умолчанию включена аудиодиагностика: первые пять строк прежние, вместо V/D/O и AU/Q/E последние две показывают K/W/C/H/X и AU/S/Z. Значения описаны в разделе «Диагностика MMAPI 0.27.9» [README](../README.md). Число строк и размер буфера прежние. Левой клавишей: аудиодиагностика → обычная подробная → краткая → выключено → аудиодиагностика. Накопительные C/H/X ограничены на экране 999/999/99; они не являются процентами кэша C/R.

# Экранные счётчики 0.27.4–0.27.6

В экспериментальной 128×160 панель включена сразу. Левая софт-клавиша переключает **подробно → кратко → выключено → подробно**. Удержание клавиши не перелистывает режимы. Правая софт-клавиша открывает прежнее меню. Клавиши игры, `*`, `#` и инвентарь сохраняют назначение. Подсказка добавлена в первый экран «Помощи».

Панель располагается внизу игрового поля поверх сцены. В обычных локациях инвентарь остаётся ниже неё. В отдельных головоломках панель накладывается на нижнюю часть экрана; её можно свернуть или скрыть левой клавишей.

Числа обновляются примерно раз в секунду. В парах времени `последнее/максимум` обе величины указаны в миллисекундах. Максимумы и минимум свободной памяти сбрасываются при входе в локацию. Переключение вида панели перезапускает окно подсчёта частот, но не стирает максимумы.

| Обозначение | Значение |
| --- | --- |
| `F` | Выполненных вызовов Canvas.paint в секунду, с десятичной долей. Это частота отрисовки приложения, а не измерение обновления самого LCD. Включает перерисовки курсора и панели. |
| `T` | Проходов обновления игрового Canvas в секунду; это не число скриптовых шагов по 100 мс. |
| `A` | Обновлений основной сцены, которые запросили перерисовку из-за изменения состояния, в секунду. Помогает отличить неподвижную сцену от низкого F. В статичных отдельных головоломках A может быть нулевым. |
| `S2/500` | Внутренний номер сцены и длительность её последней загрузки. Вход в зоопарк — сцена 2; загрузка в примере заняла 500 мс. |
| `U` | Время обновления игрового Canvas: последнее/максимальное. Включает загрузку кадров во время этого обновления и возможные паузы VM. |
| `P` | Время рисования сцены: последнее/максимальное, без самой панели. |
| `G` | Максимальный интервал между отрисовками после входа в локацию; ожидание неподвижной сцены тоже входит в него. |
| `L` | Последнее/максимальное время открытия ресурса через общий загрузчик либо полного чтения банка тайлов, включая его распаковку и выделение массива. Чтение обычного ресурса после возврата потока сюда целиком не входит; полная загрузка сцены измеряется S. |
| `B+` | Число заново прочитанных банков тайлов за последнее окно счётчиков. Попадания в кэш банков сюда не входят. |
| `I+` | С 0.27.6: число чтений небольших линейных групп полных кадров за окно. Повторное использование уже загруженной группы не увеличивает счётчик. Сумма B+ и I+ — число загрузок данных графики; размер одной группы может сильно отличаться от размера тайлового банка. |
| `C` | Процент попаданий в кэш декодированных индексных кадров за окно. При отсутствии запросов показывается 0%. |
| `R` | Процент попаданий в кэш уже масштабированных изображений за окно. При отсутствии запросов показывается 0%. |
| `M900/2048K` | Занято/доступно в текущем Java heap, в КиБ. Это не свободное место для JAR и не вся память телефона; часть нативных изображений/медиабуферов может учитываться отдельно VM. |
| `N` | Минимум свободного Java heap, замеченный при секундных выборках, в КиБ. Это не точный счётчик GC: CLDC не предоставляет такой счётчик. |
| `V4/16` | Объектов с флагом visible / всего объектов в Scene.actors. Сюда могут входить объекты вне экрана. Специальные режимы могут рисовать собственные объекты вне этого списка. |
| `D` | Время самой диагностической панели: последнее/максимальное, включая обновление надписей и вывод. Позволяет оценить влияние измерений. |
| `O+` | Число открытий ресурсов общим загрузчиком за окно. Банки открываются отдельно и отражаются в B. Попадания в кэш не увеличивают O. |
| `AU` | Подготовка и запуск звукового эффекта: последнее/максимальное, включая открытие потока, MMAPI realize/prefetch/start и возможные повторные попытки. |
| `Q` | Текущая длина очереди звуковых событий. |
| `E` | Число занятых плееров эффектов; MIDI сюда не входит. С 0.27.8 включает до одного завершённого плеера шагов, сохранённого на срок до 1,5 секунды. |
| `H+` | С 0.27.8: удачные повторные запуски готового плеера шагов за окно измерения (до 99). Первый запуск требует обычной подготовки; повторный перематывает плеер на начало. |

Значения времени ограничены 9999 мс: такое число может означать и более длинную задержку. B/O ограничены 999 за окно. Мелкие операции могут давать 0 мс из-за разрешения часов телефона.

Для обновления показаний в неподвижной основной сцене панель просит перерисовать только свою область не чаще раза в секунду. Поэтому F около 1 при A=0 само по себе не означает тормоза. На полностью статичных экранах отдельных головоломок без работающего игрового таймера панель обновляется при очередной отрисовке/нажатии.

Нет отдельного диагностического потока и вызовов System.gc(). Шрифт — небольшой встроенный bitmap, выводится одним drawRGB. Буфер переиспользуется: до 28 КиБ в подробном режиме и до 8 КиБ в кратком. Выключение освобождает ссылку на буфер и прекращает диагностические запросы repaint; лёгкие счётчики времени остаются. При нехватке памяти панель автоматически скрывается.

Для следующей записи полезно оставить подробный режим: сначала показать несколько секунд без движения курсора, затем тот же участок с движением. Нужны прежде всего F/T/A, U/P/G, L/B/C/R, M/N и D; AU/Q/E покажут, совпадают ли паузы с подготовкой звука.
