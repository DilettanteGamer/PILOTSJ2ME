# J2ME-версии и сборка

[План переноса](../docs/J2ME_PORTING_PLAN.md) ·
[Игровые механики 0.4.2](../docs/FIRST_LOCATION_ITEMS.md)

- `input/` — предоставленные JAR 0.3.2, без изменений; SHA-256 в `baselines.json`.
- `src/pilots/` — восстановленные и исправленные Java-исходники движка.
  Выбор героя, окно, инвентарь, чайник, бочка и цепочка кота; сохранение состояния.
- `dist/` — сборки 0.4.2 для 128x128 и 240x320, JAD и отчёты.
- `tests/` — проверки состояния и связывания ресурсов без экрана.
- `analysis/decompiled/` — исходный CFR 0.152 вывод для изучения, до исправлений.
- `analysis/inventory.json` — статическая опись исходных и текущих JAR.

Полный JDK, Python 3.9+; сеть нужна для первой загрузки инструментов:

```sh
export JAVA_HOME=/path/to/jdk
./j2me/build.sh
python3 j2me/analyze.py
```

Сборка проверяет SHA-256 исходных JAR и инструментов, компилирует Java с API
CLDC 1.1 / MIDP 2.0, выполняет CLDC preverification через ProGuard и запускает
тесты новой логики, включая сравнение с байткодом оригинальных правил
окна, инвентаря, бочки и кота.
Отсутствовавшие общие позы и реакции извлекаются из закреплённого `PILOTS.EXE`. Кэш инструментов по умолчанию `/tmp/pilots-j2me-tools`;
его можно изменить через `--tool-cache` или `PILOTS_TOOL_CACHE`.
Другие параметры: `--profile all|128x128|240x320`, `--out /path/to/output`.

В игре: `1` — Шеф, `3` — Коллега, `2/4/6/8` — курсор, `5` или касание —
действие. `#`, касание нижней панели или меню → «Инвентарь» — выбор предмета.
Чайник можно взять у двери, затем применить к бочке. Порядок действий
с окном и вороной влияет на исход; правила восстановлены из оригинала.
Ходьба, остальные предметы и полная головоломка ворот ещё переносятся.

Существующие анимации уже проверены пользователем; их воспроизведение здесь
повторно не тестируется. Сохранены все существующие визуальные ресурсы и
привязки 0.3.6, включая удаление «Детали». Проверка на телефоне/эмуляторе
не выполнялась. Размеры сжатых JAR могут зависеть от версии zlib.

Для исторической ресурсной упаковки без компиляции:
`python3 j2me/build.py --out /tmp/pilots-resources-0.3.6`.
