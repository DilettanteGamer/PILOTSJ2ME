- `input/` — предоставленные JAR 0.3.2, без изменений; SHA-256 в `baselines.json`.
- `src/pilots/` — восстановленные и исправленные Java-исходники движка.
  Пять прежних локаций, вступление и интерьер гостиницы, комната с балконом, карниз, ванная, электрощитовая, подвал, крыша и полёт, нижняя панель и сохранения.
  Канализация — мини-игра за Коллегу с управлением 4/6 и автоматическим повтором после падения.
- `dist/` — отдельные сборки 0.24.4 для 128x128, 128x160 и 240x320, JAD и отчёты.
- `profiles.json` — независимые настройки сборки и лимита кэша каждого профиля.
- `tests/` — проверки состояния и связывания ресурсов без экрана.
- `analysis/decompiled/` — исходный CFR 0.152 вывод для изучения, до исправлений.
- `analysis/inventory.json` — статическая опись исходных и текущих JAR.

Полный JDK, Python 3.10+ и Pillow (версия закреплена в `requirements.txt`);
сеть нужна для первой загрузки инструментов и Python-зависимостей:

```sh
export JAVA_HOME=/path/to/jdk
python3 -m pip install -r j2me/requirements.txt
./j2me/build.sh
python3 j2me/analyze.py
```

Сборка проверяет SHA-256 исходных JAR и инструментов, компилирует Java с API
CLDC 1.1 / MIDP 2.0, выполняет CLDC preverification через ProGuard и запускает
тесты новой логики, включая сравнение с байткодом оригинальных правил
окна, инвентаря, бочки и кота.
Отсутствовавшие общие позы и реакции извлекаются из закреплённого `PILOTS.EXE`. Кэш инструментов по умолчанию `/tmp/pilots-j2me-tools`;
его можно изменить через `--tool-cache` или `PILOTS_TOOL_CACHE`.
Другие параметры: `--profile all|128x128|128x160|240x320`, `--out /path/to/output`.
Для Nokia C1-02 предназначена отдельная сборка `Pilots-128x160.jar`.
Имена приложений различаются, поэтому профили устанавливаются отдельно
и имеют собственные RMS-сохранения. Общий движок сохраняет адаптацию к
фактическому размеру экрана; жёсткой обрезки под объявленное разрешение нет.

Нижние квадраты выбирают персонажей, руку и полученные предметы: чайник,
кирку и монету. Клавиши: `1/3` — герои, `2/4/6/8` — курсор, `5` — действие,
`7` — предмет, `9` — герой, `#` — инвентарь, `0` — меню. Главное меню:
«Новая игра», «Продолжить», «Локации», «Звук вкл./выкл.», «Об игре», «Выход».
Новая игра запрашивает подтверждение, если игра уже начата. Сохранения
выполняются автоматически при открытии меню, сворачивании, выходе и переходе
между локациями. Разблокированные локации сохраняются отдельно от новой игры.

В подменю «Локации» доступны только уже открытые игроком сцены; вход в зоопарк доступен всегда. Текущий маршрут:
ворота → двор зоопарка → звериный двор → сад → улица → канализация → гостиница
(вступление и интерьер) → комната с балконом → карниз → ванная →
электрощитовая → подвал → крыша → полёт → финальная поляна. Переходы
между сценами автоматические. После исходного эпизода со слоном показывается завершение.

Отладочный список анимаций убран из главного меню. Игровые ресурсы
и внутренний каталог проверки канализации сохранены. В «Об игре» — семь
оригинальных страниц титров и автор переноса; 4/6 листают страницы, 5
увеличивает, 2/4/6/8 перемещают увеличенную страницу, 0 возвращает в меню.
На крыше нижняя строка отображает обе краски, ножницы и лестницу.
Клавиша `7` перебирает все четыре предмета, `#` открывает инвентарь.
В полёте: `2` — верх, `5` — середина, `8` — низ, `0` — меню.
Нижняя строка показывает выбранную высоту и остаток балласта.

Сборка проверяет исходные правила, сквозные маршруты, ходьбу, подписи,
переходы, сохранения PSV1/PSV2 и HWS1, исходные звуковые события,
PCM/MIDI, жизненный цикл MMAPI и настоящий рендер сцены и панели
во всех трёх профилях. Все упакованные кадры проходят декодирование
с проверкой контрольных сумм; отдельные проверки отрисовки охватывают
масштабирование и обрезку у края экрана. Заглушка `Graphics` моделирует
драйвер с проверкой полного шага строки `drawRGB`.
Кэшируются фон, панель, экранные растры спрайтов и два последних цикла ходьбы.
Прокрутка сдвигает существующее изображение фона и масштабирует только
открывшиеся полосы; небольшие полосы передаются одним блоком `drawRGB`.
Движение курсора без сдвига камеры и смены подписи обновляет его старую
и новую области, сохраняя исходный clip и пропуская незатронутые спрайты/панель.
Графический кэш ограничен 256 КиБ для экранов шириной меньше 200 пикселей
и 512 КиБ для остальных (по четыре байта на пиксель, без накладных расходов
реализации Image). При нехватке памяти используется резервная отрисовка.
Крупные анимации упакованы ANM3/RLE, если это уменьшает ZIP; остальные ANM1.
Фоны ещё не перенесённых локаций исключены из dist; исходники ресурсов
остаются в input/ и оригинальном EXE. Игровые ресурсы всех перенесённых локаций и звук сохранены.
Версия 0.24.4 совмещает подъём Коллеги с нижней лестницей канализации и показывает её целиком. Графическое меню, постоянные открытия локаций и автоматическое продолжение сохранены; ожидает проверки на устройствах.
Палитры, координаты и распакованные пиксели сохранены побайтово; новые спрайты двора
извлекаются из закреплённого EXE. Уход вороны (старый номер 18) исправлен;
остальные её кадры не переделывались. Звук и музыка перенесённых локаций включены; меню «Звук: вкл/выкл»
управляет воспроизведением. Точный нативный поиск пути GMW ещё требует переноса. Размеры сжатых JAR могут зависеть от zlib.

Для исторической ресурсной упаковки без компиляции:
`python3 j2me/build.py --out /tmp/pilots-resources-0.3.6`.
