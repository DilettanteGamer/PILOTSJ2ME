# Иконка релизных сборок 0.26.1

В трёх релизных JAR добавлена PNG-иконка 32×32 из оригинального AUTORUN.ICO. RGBA-пиксели проверены на точное совпадение; масштаб не изменён. Атрибут MIDlet-1 в manifest и JAD указывает /icon.png. Игровые классы и все прежние ресурсы побайтно сохранены. Изменены только номер версии, иконка, manifest/JAD и отчёты упаковки.
