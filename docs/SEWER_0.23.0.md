# Канализация — 0.23.0

По новому решению пользователя ранее исключённая канализация включена
в прохождение. Переходы теперь: улица (6) → канализация (7) → вступление
перед гостиницей (8). В подменю локаций добавлена «Канализация». Сохранения
предыдущих уровней не направляют игрока назад: уже начатая гостиница
и более поздние сцены продолжаются на прежнем месте.

## Экран и управление

Используется секция 9 закреплённого PILOTS.EXE. Фон обрезан до прямоугольника
(104,144,432,208): труба-мост и края обеих платформ. Этот участок целиком
масштабируется по ширине экрана без горизонтальной прокрутки. Пропорции
спрайтов сохраняются, по вертикали участок центрируется. Внешние области
имеют тёмный цвет канализации, внизу — краткая подсказка управления.
Графика за пределами обрезанного участка отсекается.

Играет только Коллега. 4/влево — шаг влево, 6/вправо — шаг вправо.
Один шаг исходной сетки 64 пикселя длится 4 такта по 100 мс. Удержание
клавиши использует обычные повторные события телефона. Коллега начинает
на правой платформе (448,256) и завершает переход на левой (128,256).
Нет инвентаря, игрового курсора, переключения персонажей или дополнительных
кнопок действия. Клавиша 0 открывает меню; при скрытом экране таймер
останавливается. Меню инвентаря из этой сцены не открывается.

## Мыши, падение и повтор

SewerLogic сохраняет трёх исходных мышей и их 20-тактовые циклы:

| Мышь / анимация | Опорная точка | Опасная фаза |
| --- | --- | --- |
| 15 / 46 | 192,160 | 14–20 |
| 16 / 47 | 256,160 | 6–11, только при движении |
| 17 / 48 | 384,160 | 9–16 |

Для кнопочного управления пространственные проверки сведены к одной линии
передвижения. Окна опасности взяты из исходных правил объектов 15–17;
полная PC VM для этой мини-игры не запускается. Дополнительные мыши
из исходных анимаций сохраняются в пределах обрезки. Никакой новый
нарисованный спрайт не используется.

При столкновении проигрывается исходная анимация падения Коллеги 64,
затем он автоматически появляется в исходной правой точке через 24 такта.
Направления во время падения игнорируются. Количество попыток не ограничено;
таймер мышей продолжает работать. После одного успешного перехода
автоматически начинается вступление перед гостиницей. Второе прохождение
моста Шефом и длинные исходные сцены вылезания из воды исключены по запросу.

## Ресурсы и сохранения

Извлечены 31 исходный клип / 360 кадров с неизменными палитрами, пикселями
и опорными точками, 26 WAV с исходным PCM и MIDI 85,28 с / 8523 события.
Шаги и падение используют исходные звуковые номера. Добавлено 16 анимаций
канализации в список проверки; предыдущий активный список финала очищен.
Игровые спрайты остальных сцен сохраняются.

SWR1 хранит таймер, обе опорные точки шага, направление, фазу движения,
фазу и точку падения, число попыток и завершение. Используется существующее
расширение GameState.location; новое состояние проверяется при загрузке.
Сохранение в меню и продолжение работают посреди шага и падения.

## Проверки

- SewerWorldTest: невозможные кнопки, столкновение при поспешном движении,
  автоматический повтор без сброса времени, один Коллега, решение через
  обычные команды и сравнение состояния после загрузки на каждом такте.
- SewerRenderTest: настоящее изображение моста и мышей, отсутствие панели,
  пауза, падение, возврат и прохождение для трёх разрешений.
- LocationEntryTest: вход из меню и улицы, настоящие клавиши 4/6, сохранение
  в RMS посреди шага, меню по 0, переход в гостиницу после одного прохождения,
  вход и выход из нового списка анимаций.
- SewerAssetsTest: независимая сверка всех кадров и обрезки с оригинальными
  записями EXE; отсутствие старых ресурсов инвентаря и хотспотов канализации.

Полная сборка 128×128, 128×160 и 240×320 прошла, включая CLDC preverification,
проверки прежних локаций и декодирование 1661 клипа / 20772 кадров.
В каждом архиве 2266 прежних ресурсов совпадают с 0.22.3; изменён каталог
сцен, список предпросмотра финала заменён канализацией, добавлены только
новые игровые ресурсы сцены 7. CRC и JAD корректны. Отчёты:
`j2me/analysis/sewer-assets-audit.json`, `j2me/analysis/sewer-release-audit.json`.

Автоматические проверки не заменяют тестирование на реальных устройствах.
