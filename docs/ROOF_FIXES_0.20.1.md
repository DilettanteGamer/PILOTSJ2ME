# Крыша: шланг, подписи и ожидание в корзине — 0.20.1

Исправлены три замечания к 0.20.0.

1. У шланга появилась постоянная область выбора: `144 ≤ X < 216`,
   `316 ≤ Y < 390` в координатах исходного фона. Она охватывает все четыре
   позы и запас для шага кнопочного курсора. Область действует только пока
   шланг доступен для подключения; передний персонаж сохраняет приоритет.
2. Во время действий и катсцен крыши подписи объектов под курсором скрыты.
   Поэтому анимации покраски светофора и отрезания верёвки не подписываются
   как «Коллега». Настоящие текстовые реплики продолжают отображаться.
3. Устранено зависание при ожидании в наполненном шаре. Общий контроллер 5
   через 250 свободных тактов запускал действие 32 для наземного Шефа.
   После посадки Шеф заменён объектом 47; у него нет обработчика действия 32.
   Аналогичная проблема существовала у действия 33 для Коллеги в корзине.
   Наземные фоновые реакции приостанавливаются, пока брат находится в корзине
   или выполняется маршрут. При спуске контроллер 8 сохраняет флаг занятости
   до завершения исходной анимации, затем продолжается выбранный маршрут.

Сохранения 0.20.0 с таким незавершённым фоновым действием восстанавливаются
без сброса головоломки: снимаются только действие 32/33 и его таймеры, если
соответствующей наземной фигуры уже нет. Краска, светофор, наполненность
шара, предметы и положение второго брата сохраняются.

`RoofWorldTest` повторяет порядок из пользовательского теста: наполнить шар,
посадить Шефа, подождать, покрасить светофор Коллегой, подождать, посадить
Коллегу и отрезать верёвку. На каждой паузе выполняются 1200 тактов; снимок
после каждого такта сверяется с заново загруженной копией. Отдельно проверяется
зависшее сохранение 0.20.0, созданное прежней сборкой, и прохождение после
его восстановления. Вместе с прежним маршрутом — 7451 проверка восстановления.

`RoofRenderTest` проверяет одну неподвижную точку вне видимых пикселей шланга
на всех четырёх кадрах, затем подключает его через эту точку. Тест проходит
позднюю покраску при Шефе в корзине, ожидание обоих братьев и финал через
реальные хотспоты. Во время покраски и работы с верёвкой проверяется
отсутствие подписи персонажа. Проверки выполняются для трёх разрешений.

Графика, байткод игровых правил, звук, музыка и каталог анимаций не менялись.
Полные проверки трёх профилей пройдены. CRC архивов и размеры из JAD
совпадают. Все 1993 прежних ресурса каждого профиля побайтово сохранены;
контрольные суммы записаны в `j2me/analysis/roof-fixes-release-audit.json`.

Это проверки на JVM; следующая проверка — на устройствах.
