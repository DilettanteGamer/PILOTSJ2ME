# Текстовые титры и правая клавиша — 0.26.0

Во всех графических Canvas удалены зарегистрированные системные команды MIDP. Некоторые реализации MIDP даже при одной команде BACK открывают нативное контекстное меню вместо передачи клавиши приложению. Теперь правая клавиша (`-7`) обрабатывается самим Canvas: в игре открывает меню, в главном меню возвращает в текущую игру, в «Локациях», «Помощи» и «Об игре» возвращает назад. В отдельных головоломках правая клавиша напрямую закрывает экран; прежняя кнопка 0 в этих головоломках сохранена. Системная команда остаётся только в аварийном Alert при ошибке запуска.

Семь растровых страниц титров исключены из JAR. Вместо них используется полный текст, предоставленный пользователем, с сохранением оригинального шрифта и кожаного фона секции 20. Отмеченные пользователем фрагменты отображаются жёлтым (#FFE35A), остальные — светлым (#FFFBF0), без служебных скобок. Фон подготовлен в точном разрешении профиля.

Текст разбивается на строки по ширине экрана и на страницы по доступной высоте. Основной размер оригинального шрифта — 16 для 128×128/128×160 и 24 для 240×320; длинные слова используют размер не меньше 12. Это уменьшение отдельных текстовых строк, а не сжатие всей страницы. На каждом экране доступны 2/4 — предыдущая страница, 6/8 — следующая; правая клавиша — назад. Есть номер страницы, поддержаны касания. Последняя отдельная страница содержит «Перенос на J2ME» и полное имя Данила "DilettanteGamer" Григорьев.

GraphicalMenuTest проверяет отсутствие нативных команд в игре и графических подменю, прямой возврат правой клавишей, перенос полного текста без потерь и перестановок, сохранение выделения каждого символа, ширину каждой строки, минимальный размер шрифта и цельную последнюю страницу автора на всех трёх разрешениях. MenuAssetsTest проверяет исходные шрифты/фон и отсутствие растровых титров в каждом JAR. Проверка на реальном телефоне остаётся за пользователем.
