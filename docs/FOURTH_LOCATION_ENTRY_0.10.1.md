# Загрузка четвёртой локации, 0.10.1

В 0.10.0 ресурсы сада и переход из звериного двора были добавлены, но
`GameCanvas.goToScene` продолжал разрешать только внутренние номера 2, 3, 4.
Поэтому вход из меню и переход после третьей локации завершались ошибкой
`java.io.IOException: This build includes locations 1, 2 and 3`.

Теперь допустимость сцены проверяется по упакованному `catalog.bin`:
2, 3, 4, 5 (четыре игровые локации). Проверка выполняется до освобождения
ресурсов текущей сцены. Несуществующие номера по-прежнему отклоняются.
Игровые правила и ресурсы сада не изменены.

Добавлен `LocationEntryTest`, запускающий настоящий `PilotsMidlet.GameCanvas`
из готового JAR с настольными заменами экранных классов MIDP. Эти замены
используются только тестом и не включаются в телефонную сборку.
Проверяются прямой вход, выбор четвёртой локации через обработчик меню,
переход после установленного признака завершения третьей, загрузка
сериализованного состояния сада, вход в предпросмотр и возврат в игру,
отклонение отсутствующей сцены без замены текущей.

На опубликованной 0.10.0 тест воспроизвёл исходную IOException. В сборочный
сценарий добавлен запуск этой проверки для каждого из трёх профилей.
Она не заменяет проверку меню и прохождения на настоящем телефоне;
финал третьей локации в ней задаётся напрямую, остальные игровые проверки
выполняются существующими тестами.

Сборки 0.10.1: [128×128](../j2me/dist/Pilots-128x128.jar),
[128×160](../j2me/dist/Pilots-128x160.jar),
[240×320](../j2me/dist/Pilots-240x320.jar). Имена приложений и формат
сохранений сохранены.
