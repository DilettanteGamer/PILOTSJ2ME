# Третья локация: голова жирафа и выход персонажей, 0.9.6

## Основная поза после временной анимации

Во вступлении оригинал сначала задаёт статичную позу головы жирафа 115,
продолжает проверку правил (`native 00`), затем запускает реакцию 131.
По завершении реакции должна снова отображаться основная поза. Порт
хранил только текущий клип: временная анимация удалялась вместе с головой.

Теперь сохраняется основная поза, заданная перед временной анимацией.
После окончания возвращается она; признак завершения остаётся доступным
исходным правилам. Аналогично обрабатываются пары 117 → 116, 120 → 119,
136 → 135 и подготовленные позы героев. У временных составных изображений
без основной позы сохраняется очистка из 0.9.5: лишний Шеф после носорога
не возвращается. Исходные клипы, правила и звук не изменены.

## Обходы

К исходной грубой сетке 64x16 добавлены ограничения для точек опоры ног
на сетке перемещения 16x16:

- чаша и перемычка у крана: `176 ≤ x < 320`, `256 ≤ y < 304`;
- внутренняя область вольера кенгуру: `16 ≤ x < 144`, `304 ≤ y < 400`.

Точка взаимодействия Шефа с кенгуру `(0,352)` сохранена. От неё Шеф
спускается по левому краю и обходит вольер по дорожке при `y=400`, затем
идёт к выходу `(576,368)`. Путь к крану `(128,288)`, инструментам и места
приземления Коллеги остаются доступными. Прямой проход между краном и
чашей закрыт для обоих героев, включая движение по нажатию на пустое место.

Ограничения реализованы в адаптере маршрутов J2ME; исходные карты и
условия головоломки не переписывались.

## Коллега после освобождения

После всех 40 кадров клипа 125 Коллега возвращается в обычного героя
в `(384,352)`: эта позиция соответствует окончанию составного изображения
и подготовленной статичной позе 122. Составное изображение отключается,
чтобы не оставлять второго Коллегу. Герой остаётся видимым, пока Шеф
обходит вольер, затем идёт вслед за ним к выходу.

Исходный предикат завершения контроллера 71 проверял только позицию Шефа.
Адаптер теперь завершает локацию после прибытия обоих героев и окончания
ходьбы. При этом остаются все кадры выпадения Коллеги, появления ключа и
похищения ключа мартышкой, восстановленные в 0.9.5.

Исправлена также очистка служебных маркеров 6/7: удаляется маркер карты,
а не персонаж, стоящий в той же клетке. Иначе достигший точки маршрута
герой мог стать неактивным.

## Сохранения и проверки

Снимок AWS4 дополнительно хранит основную позу каждого объекта. Читаются
AWS1, AWS2 и AWS3; при загрузке старых снимков восстанавливаются пропавшая
голова и известные подготовленные позы временных сцен. Старые версии игры
не читают AWS4. Первые две локации сохраняют прежние форматы.

`AnimalSequenceRenderTest` проверяет голову на каждом тике вступления,
все 18 кадров реакции и возврат позы 115, сохранение и ожидание после
вступления. Дополнены проверки обхода чаши и вольера, видимости Коллеги
после освобождения, последовательности выхода героев и сохранения посреди
ходьбы Коллеги. Прежние проверки всех кадров срезания и финала сохранены.
Есть настоящий снимок 0.9.5 после вступления для проверки восстановления
головы при загрузке, а также снимки 0.9.3 и 0.9.4.

Полная сборка выполняет проверки трёх локаций, вариантов фонтана, звука,
ресурсов, RGB, прокрутки и панели для 128x128, 128x160 и 240x320.
Это проверки на настольной JVM; сборку ещё нужно проверить на устройствах.
Четвёртая локация не добавлена. Уже завершённое старое сохранение остаётся
завершённым; для повторной проверки финала можно открыть третью локацию
заново через меню.
