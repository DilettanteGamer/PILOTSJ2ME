# Маршруты финальной поляны — 0.22.1

Исправлен проход Шефа по воздуху между ветками. Поиск пути финальной сцены
использует четыре соседние клетки, как исходный поиск в PILOTS.EXE
(FUN_00407e10). Направление native 26 соответствует первому шагу, а native 27
для диагонального движения по ветке объединяет первые два соседних шага
(FUN_00407964). Диагональ через заблокированный угол больше не создаёт
несуществующий проход между раздельными ветками.

Для совместного прыжка контроллер 20 проверяет обоих участников: прыгающий
герой находится на конце нижней ветки (192,272), второй — под ним между
левым и центральным деревом (128,352). Ранее дополнительная проверка J2ME
ошибочно требовала позицию помощника от самого Шефа. Теперь нажатие слева
запускает исходную анимацию 76 и переводит Шефа на левую ветку. До прихода
Коллеги такой переход недоступен.

Проверка полного прохождения теперь повторяет порядок пользователя:
табуретка → нижняя ветка → Коллега под веткой → прыжок через голову →
попытка достать слугу → упавшая флейта → Коллега на ветке → флейта на
дупло → кот и вторая флейта → подъём Шефа через слугу → флейта на ёлке →
лестница из трёх флейт → четвёртая флейта → слон и исходный финал.
Отдельно проверяется невозможность перейти на левую ветку без помощника.

FinalWorldTest сравнивает сохранённое и непрерывное состояние на каждом
из 1494 тактов полного прохождения и проверяет действие 23 и звук 25 прыжка.
FinalRenderTest выполняет тот же путь через настоящие хотспоты сцены,
включая применение флейты на дупло, и сохраняет новый кадр после прыжка.
Оригинальные карты, сценарии, спрайты и звук не изменялись.

Проверка архивов подтвердила совпадение всех 2268 ресурсов каждого профиля
с 0.22.0. Изменены только HotelWorld.class и версия в манифесте. CRC
архивов, версии и размеры в JAD корректны; отчёт:
`j2me/analysis/final-routing-release-audit.json`.

Полная сборка и общие проверки предыдущих локаций прошли для 128×128,
128×160 и 240×320; включая проверку ресурсов по оригинальному EXE и
CLDC preverification.

Автоматические проверки не заменяют тестирование сборки на телефонах.
