# Совместимость отрисовки — 0.8.1

Сборки: [128×128](../j2me/dist/Pilots-128x128.jar),
[240×320](../j2me/dist/Pilots-240x320.jar).

На реальном устройстве пользователь сообщил `ArrayIndexOutOfBoundsException`
при открытии игры, выборе локации и предпросмотре анимации в 0.8.0
на Nokia C1-02 (экран 128×160). Стек исключения с телефона недоступен.

В общем рендерере `AnimationClip.paint` обнаружен зависимый от драйвера вызов:
непрозрачный участок передавался в `Graphics.drawRGB` со смещением внутри
массива и шагом строки, равным всей ширине спрайта. Например, первая иконка
панели передавала массив из 20 элементов, offset=3, scanlength=20,
width=17, height=1. По MIDP такой доступ допустим: используются элементы
3–19. Но проверка полного шага `offset + height * scanlength` требует
23 элемента и выбрасывает исключение. Прежняя настольная заглушка
проверяла только фактически читаемые пиксели и пропускала этот случай.

В 0.8.1 каждый непрозрачный участок сдвигается в начало существующего
буфера. Вызов получает offset=0 и scanlength=width. Дополнительные массивы
на каждый участок не создаются, прозрачные промежутки остаются прозрачными.
Перенос происходит только в уже обработанную часть строки, поэтому
последующие участки не повреждаются.

Проверки:

- На опубликованной 0.8.0 заглушка с проверкой полного шага воспроизводит
  `ArrayIndexOutOfBoundsException` в `AnimationClip.paint → ZooPanel.paint`.
  Это модель ограничения драйвера, а не воспроизведение на телефоне пользователя.
- Все 3819 кадров всех 305 упакованных ANM проходят через рабочий рендерер
  с обычным масштабом, увеличением и обрезкой по верхнему/левому краю,
  для обоих профилей, с той же проверкой полного шага. Дополнительно оба
  профиля проверяются на размере экрана Nokia C1-02 — 128×160, включая панель.
- Проверяются изображения панелей и трёх локаций, игровые правила,
  переходы, сохранения и звук; CLDC preverification выполняется при сборке.
- Все 20 контрольных PNG побайтово совпадают с предыдущими версиями:
  замена передачи RGB не изменила вид сцен и панелей.

Проверка на устройстве ещё нужна: открыть «Продолжить», «Новая игра»,
вторую и третью локации и один предпросмотр анимации. Без стека с устройства
нельзя утверждать, что найденный случай полностью объясняет исходный сбой.
Для Nokia C1-02 рекомендуется JAR с ресурсным профилем 128×128;
движок сам использует фактический размер экрана 128×160.
Если ошибка сохранится, нужны модель телефона, версия JAR и имя класса/метода
из подробностей исключения.
