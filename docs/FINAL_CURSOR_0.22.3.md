# Курсор у концов веток — 0.22.3

По уточнению пользователя убраны постоянные золотистые квадраты с концов
веток. Сами четыре активности, расширенные зоны выбора, привязка к точной
клетке и подпись «Конец ветки» сохранены. При наведении курсор становится
жёлтым через существующий механизм targetAt → GameCanvas.paint, как над
остальными активными объектами; вне зоны возвращается белый цвет.

Из HotelScene удалён только вызов и метод рисования квадратов. Исправленное
положение Шефа на изгибе верхней ветки сохраняется. Новые игровые ресурсы
и дополнительные состояния курсора не требуются.

Для проверки используются существующие FinalRenderTest (активные зоны,
подписи, нажатия рядом с концом ветки, верхний изгиб и весь финал) и общая
сборка трёх профилей. Проверки 128×128, 128×160 и 240×320 прошли.
CRC и JAD корректны. Все 2268 ресурсов в каждом профиле совпадают с 0.22.2;
отчёт: `j2me/analysis/final-cursor-release-audit.json`.
